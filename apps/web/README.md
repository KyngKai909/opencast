# @opencast/web

The Opencast app: the viewer at `/`, master control at `/control`, and Network desk at `/desk` for
the Opencast team, as areas of one app with one sign-in. `npm run dev` on :5173 against the API,
`npm run dev:mock` on :5174 on mock data. The iPhone and Android apps wrap it with Capacitor
(`npm run build:native`, docs/apps/native.md). Owned by the apps prompt (`docs/prompts/2-apps.md`).
